# ByUs 시작 문의와 파트너 협업 제안

조사·반영일: 2026-09-11. 공식 사이트 5곳의 소개 화면과 공개된 시작·문의 동선을 Aside에서 확인했다. 아래 이미지는 해당 공식 사이트를 직접 캡처한 화면이다. 로그인 이후 기능, 문의 제출 이후 절차, 매출·운영 성과는 검증 범위에 포함하지 않았다.

## 적용한 방향

시작 페이지의 주어는 **“팬이 있는 누구나”**로 넓혔다. 개인뿐 아니라 팀, 브랜드·IP 관계자도 활동을 소개하고 문의할 수 있다. 제목·푸터는 **“ByUs 시작 문의”**, 버튼은 **“ByUs 시작 문의하기”**로 바꿔 다음 행동을 분명히 했다. 기존 `/pages/creator-onboarding` 경로와 내부 문의 유형은 유지했다.

파트너 페이지는 **커머스·공동구매 / 라이브커머스 / 굿즈·IP 협업 / 광고·브랜디드 콘텐츠 / 팬 혜택·이벤트**를 제안받는다. 각 분야에 ByUs의 팬 인증, LIVE 예약·출석, 응모·추첨을 활용하는 방법을 설명했다. 문의창에도 같은 분야 선택과 ‘아직 정하지 못했어요 / 기타’를 넣었다.

이 문구와 다섯 분야의 조합은 ByUs용으로 새로 정리한 것이다. 특정 서비스의 문구를 그대로 가져오거나 업계 공통 기준으로 제시하지 않는다.

## ByUs 현재 기능과의 적합성

| 제안 분야 | ByUs에서 활용할 수 있는 기능 | 문의에서 확인할 조건 |
|---|---|---|
| 커머스·공동구매 | 제품 소개, 관련 LIVE·팬 참여 혜택 안내 | 제품, 희망 협업 대상, 판매 채널, 가격·제공 조건 |
| 라이브커머스 | 외부 LIVE 안내, 예약, 출석, 연계 혜택 | 방송 채널·일정, 출연자, 상품, 방송·판매 운영 주체 |
| 굿즈·IP 협업 | 공개 일정 안내, 팬 인증과 이벤트 | IP·디자인 사용 범위, 제품, 제작·판매·배송 역할 |
| 광고·브랜디드 콘텐츠 | 콘텐츠와 연계할 팬 참여 활동·이벤트 | 콘텐츠 형식, 게시 채널, 사용 범위, 일정·예산 |
| 팬 혜택·이벤트 | 팬 인증, 응모·추첨, 당첨 혜택의 배송·현장 수령 안내 | 혜택 종류·수량, 참여 조건, 제공·수령 방식 |

팬 혜택·이벤트는 기존 참여 기능과 가장 직접적으로 맞닿아 있어 추가했다. 커머스·굿즈·광고는 파트너의 상품·콘텐츠 운영과 ByUs의 팬 참여 운영을 협의하는 제안 분야다. 네이티브 결제·주문·정산·일반 상품 배송·셀럽 자동 매칭은 현재 확인한 기능이 아니다.

현재 공개 대상의 데이터 모델은 `celebrities`와 제한된 역할 enum을 사용한다. 따라서 팀·브랜드·IP까지 **문의 대상**을 넓혔으며, 모두가 즉시 계정을 개설·공개할 수 있다는 설명은 넣지 않았다. 실제 수용 방식은 상담에서 검토한다.
