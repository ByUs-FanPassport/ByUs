## 승인한 예약 상태 방향

- 미니 캘린더와 촘촘한 일정 목록은 예약한 LIVE 제목 옆에 작은 원형 체크 배지만 표시한다. 반복되는 `예약 완료` 보조 줄은 제거한다.
- 캘린더 하단에 `체크 = 내 예약` 범례를 한 번만 제공한다. 스크린리더에는 각 이벤트의 `예약 완료` 의미를 유지하고, 데스크톱 호버/포커스 설명도 고려한다.
- 모바일에서는 기존 일정 행을 누르면 상세로 이동하여 예약 상태를 명확하게 확인한다. 일정 링크 안에 또 다른 버튼을 중첩하지 않는다.
- 미예약·로그인 전·예약 상태 확인 중을 예약 완료로 추정하지 않는다. 예약한 항목에만 체크를 붙인다.
- 날짜 셀의 일정 점은 LIVE가 존재한다는 뜻을 유지한다. 같은 날 여러 LIVE 중 하나만 예약했을 수 있으므로 날짜 전체를 예약 완료로 표현하지 않는다.
- LIVE 상세의 주 상태와 예약 직후 확인 창에는 명시적인 `예약 완료` 문구를 유지한다. 예약 전 가능한 행동과 예약된 상태는 구별한다.
- 검토한 대안인 `체크 + 내 예약` 칩은 적용하지 않았다. 선택한 표현은 원형 체크와 공통 범례이다.
- 벨은 알림 수신과 혼동할 수 있어 예약 표시에는 체크를 추천한다. YouTube 공식 도움말의 Set reminder는 알림 설정이며 ByUs의 예약 성공과 같은 의미로 취급하지 않는다.

## 승인한 시작 시간 방향

모든 화면이 같은 KST 기준을 공유하되 화면 밀도에 맞춰 길이를 조정한다.

| 상황 | 일정 목록 권장 표시 |
| --- | --- |
| 다른 KST 날짜, 시작 1시간 이상 전 | `D-3`, `D-1` 등 날짜 차이 |
| 오늘, 시작 1시간 이상 전 | `오늘 20:00` |
| 시작 1시간 이내 | `45분 후 시작` 등 남은 분 |
| 서버 상태가 live | `LIVE 진행중` |
| 시작 시간이 지났지만 live 상태 미확인 | 상태 재조회 후 `시작 확인 중` 등 안전한 표현 |
| 종료 | `종료`, D-day 제거 |

- 정확한 날짜·시각은 함께 유지한다. 상대 시간만으로 일정을 전달하지 않는다.
- 작은 목록의 `LIVE 예정` 자리에 D-day/상대 시간을 우선 배치한다. 같은 정보를 여러 배지로 반복하지 않는다.
- 큰 홈 히어로·LIVE 상세의 집중 영역은 필요한 시점에 시·분·초 카운트다운을 사용할 수 있다. 모든 캘린더 셀에서 초 단위로 갱신하지 않는다.
- 종전 D-n은 남은 시간의 24시간 단위였다. 승인한 공통 기준은 KST 날짜 차이이며 자정 경계 테스트로 확인했다.
- 카운트다운이 0이 됐다는 이유만으로 방송 중으로 바꾸지 않는다. 서버의 유효 상태와 기존 재조회 동작을 따른다.
- 시작 D-day와 예약 마감 D-day는 구별한다. `마감까지`가 필요하면 별도 라벨로 표시한다. 캘린더 API에는 예약 마감 시각이 없다.
