레퍼런스로 보강한 방향

프로필·세로형·가로형 사진은 각각 등록합니다. 같은 사진을 강제로 공유하지 않고, 같은 역할을 쓰는 화면끼리 공유합니다. 아래 자료는 모두 공식 사이트의 제품 소개·문서 예시이며, 현재 앱의 업로드 동작을 직접 실행한 증거는 아닙니다.

Steam 공식 예시 · 세로 카드와 가로 배너

공식 원본 2장을 이번 조사에서 재배치한 비교 보드입니다. 보드 배치·라벨은 실제 Steam UI가 아닙니다. 각 이미지의 등록 규격은 Library Assets 문서에서 확인했습니다. ByUs에 동일 픽셀값을 적용하는 제안은 아닙니다.

Spotify 공식 예시 · 모바일 아티스트 사진

공식 제품 소개 이미지입니다. 이 이미지 자체는 desktop header 비교가 아닙니다. avatar/header 사용처 분리는 별도 공식 도움말에서 확인했습니다.

YouTube 공식 예시 · 프로필과 배너의 일관성

공식 도움말의 배너 예시와 설명입니다. 프로필과 배너의 색상을 맞춘다는 공식 설명입니다. 프로필 사진 자체의 구도 비교나 현재 편집 UI를 검증한 것은 아닙니다.

대표 프로필목록·원형 아바타·작은 사진. 얼굴 식별이 우선입니다.
세로형 사진모바일 인물 배너·캘린더. 세로 구도에 맞는 사진을 선택합니다.
가로형 사진PC 인물 배너·가로 카드. 모바일의 가로 카드도 이 사진을 씁니다.
행사 이미지가로·세로 홍보 이미지 별도 등록. 정보 포스터는 전체 표시합니다.

등록한 구분 안에서만 함께 바뀝니다. 프로필을 교체해도 세로·가로 배너를 덮어쓰지 않습니다. 전용 사진이 없으면 다른 방향 사진을 자동 확대하지 않고, 승인된 비율 보존 표시를 사용합니다.
