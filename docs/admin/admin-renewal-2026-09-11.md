# ByUs 어드민 리뉴얼 — 2026-09-11

## 1. 개선 기획안

### 대상과 목표
운영자가 접속 후 회원 규모, 최근 성장, 팬 참여, 처리할 일을 첫 화면에서 파악하고 해당 관리 화면으로 이동한다. 기존 회원·콘텐츠·심사·발급 권한과 감사 기록을 유지한다.

작업 가정: ‘가입자’는 서비스에 가입한 `app_users` 계정이다. 유료 구독·알림 수신 동의·패스포트 보유와 구분한다. 비교 기간은 직전의 동일 시간 길이다. 실제 운영에 없는 매출·미처리 문의 지표는 만들지 않는다.

### 현재 화면에서 확인한 문제
2026-09-11 Aside의 기존 관리자 로그인으로 `/admin`, `/admin/dashboard`, `/admin/fans`, `/admin/celebrities`와 상세를 읽기 전용으로 확인했다.

- PC: 232px 내비게이션, 최대 1480px 본문, KPI 4열, 핵심 차트와 보조 현황 약 1.7:1.
- 태블릿: KPI 2열, 차트·일정은 1열. 모바일: 2열 KPI, 세로 업무 목록, 메뉴 버튼.
- Pretendard, 4px 간격 기준. 본문 14px, 보조 12px, 섹션 16px, 제목 28px, 핵심 수치 30~38px. 숫자는 tabular figures.
- 흰 바탕, 얇은 중성 경계, 보라색은 가입자·활성 메뉴에 사용. 경고·실패에는 의미 있는 상태색과 텍스트를 함께 표시한다.
- 조작 영역은 최소 44px. 포커스 표시, 실제 버튼·링크·표, 차트 수치 대안, reduced-motion을 유지한다.
- 차트는 SVG 실측 축으로 그린다. 0은 0으로 표시하며 최소 높이로 값을 부풀리지 않는다. 단위가 다른 수치를 합해 추세로 표시하지 않는다.

### 지표 사전과 실제 집계

| 지표 | 정의·원천 | 기간/주의 |
| --- | --- | --- |
| 총 가입자 | `app_users` 계정 수 | 조회 시각 이전 생성, 이용 중지 포함, 지갑 수 독립 |
| 신규 가입자 | `app_users.created_at` | KST N개 날짜, 오늘은 현재 시각까지 |
| 증감률 | `(현재-이전)/이전 × 100` | 직전 동일 시간 길이. 이전 0이면 비율 없음 |
| 오늘 활동 회원 / DAU | 기록된 사용자 행동의 고유 `app_user_id` | 오늘 KST 00시부터 현재 직전까지 |
| 30일 활동 회원 / MAU | 같은 행동의 고유 `app_user_id` | 오늘 포함 30개 KST 날짜, 일별 수를 더하지 않음 |
| 활동 측정 범위 | 크리에이터·LIVE·혜택 페이지 방문, CTA, 첫 응원·패스포트·예약·출석·미션·여정·기념품·응모 참여 | 로그인한 회원만. 익명 방문, 로그인만 한 회원, 자동 티켓 지급·당첨·배송 제외. 전체 트래픽 아님 |
| 팬 참여 건수 | 각 canonical 기록의 발생 시각 | 패스포트·첫 응원·예약·출석·경품 응모 각각 건수 |
| 공개 LIVE 분포 | 공개·미보관 LIVE + 공개·미보관 크리에이터 | 기존 `live_effective_status_at`으로 수동 override·취소 반영 |
| 심사 대기 | 수동 팬 인증 `pending` | 현재 큐 전체, 조회기간과 독립 |
| 발급 실패 | blockchain jobs `FAILED` | 현재 상태, 자동 재시도 실행 없음 |
| 알림 전송 실패 | push/external 최종 실패 | 예약 변경·취소, 발송 정책에 따른 의도적 중단 제외 |

모든 발생 지표는 `[from,to)`로 끝을 제외한다. 시작 직전은 비교 기간에, 시작 정각은 현재 기간에 포함한다. 서버가 `asOf`를 결정한다. `previousFrom`과 `from`이 비교 경계다. 주간 차트는 월요일 시작, 월간 차트는 해당 월 시작으로 묶는다. 선택기간 바깥 값을 채워 넣지 않으므로 첫 구간은 일부 주·월일 수 있다.

집계 불가와 0을 구분한다. 메인 집계 실패 시 오류와 재시도 버튼을 표시하고 거짓 0을 만들지 않는다. 기존 상세 분석의 `available`, `unavailable`, `not_applicable`, `suppressed` 의미를 유지한다.

## 3. 프론트엔드 구현 가이드

### 적용 스택
현재 저장소의 Next.js 16.3.4, React 19.2.7, TypeScript, CSS Modules, Lucide, Zod, Supabase를 그대로 사용한다. 새 UI 프레임워크로 화면 일부만 갈라지지 않도록 기존 공용 셸과 스타일을 확장했다. Tailwind/shadcn/Ant Design 전환은 이번 변경에 필요하지 않다. 현재 단순 시계열·분포는 의존성 없는 SVG와 CSS로 처리한다. 복합 축·대규모 상호작용이 필요해질 때 차트 라이브러리를 별도 검토한다.

### 구현 구조

```text
app/admin/page.tsx
  AdminOverviewDashboard — 권한, 기간, 요청, 로딩·실패 상태

    AdminOverviewContent — KPI, 업무, 차트, LIVE, 집계 기준

```

### 데이터 테이블

- 성과표: 검색 결과 수, 열별 정렬, 10행 페이지 이동, 비어 있음/조회 불가 구분.
- CSV는 현재 검색·정렬 결과 전체를 내려받는다. 화면의 한 페이지만 내보내지 않는다.
- UTF-8 BOM으로 Excel에서 한글을 읽게 하고, 따옴표·줄바꿈을 인용하며 `= + - @` 등 수식 시작 문자열을 이스케이프한다.
- 회원 목록은 API의 커서 페이지를 존중한다. 서버 전체 건수를 알지 못하면 ‘불러온 N명’이라고 표시한다. 현재 불러온 회원만 정렬하는 경우 그 범위를 밝힌다.
- 파괴적·권한 변경 작업은 일괄 편집에 넣지 않는다. 점수 변경·공개 중지 등 기존 확인과 감사 기록을 유지한다.

GitHub의 기존 Fan design system 체크는 어드민 계약을 충분히 다루지 않는다. 이번에 어드민 전용 CI를 추가해 타입 검사와 관련 컴포넌트·API 테스트를 수행한다. secret이 없는 테스트로 실행하며 production 키를 CI 테스트에 제공하지 않는다. 기존 브랜치 보호를 우회하지 않는다.

### 성능·롤백

- 첫 화면은 한 번의 집계 RPC로 처리한다. 날짜 기준 회원·활동 이벤트 인덱스를 추가하고 서버에서 count/distinct/group by를 수행한다.
- 조회 범위를 7/30/90일로 제한한다. 무제한 원장 다운로드나 1,000행 클라이언트 스캔으로 전체 수치를 추정하지 않는다.
- 차트 라이브러리 추가 없이 SVG를 사용하고, 상세표는 10행만 렌더링한다.
- 운영 캐시에 인증 응답을 저장하지 않는다. 집계의 자동 주기 폴링을 추가하지 않는다.
- 코드 롤백: 문제가 있는 릴리스 커밋을 revert하여 정상 브랜치 재배포. 긴급 시 기존 정상 Vercel deployment로 rollback.
- DB 변경은 집계 함수와 보조 인덱스를 추가하며 기존 데이터는 변경하지 않는다. 웹을 먼저 이전 버전으로 돌려도 새 함수가 남아 있어 호환된다. 필요 시 서비스 호출 중단 후 새 함수/인덱스만 제거한다.
- 일반 자동 배포는 푸시와 정확한 커밋의 배포 시작까지 보고한다. 최종 배포 완료나 운영 동작 검증은 실제 확인했을 때만 기록한다.

## 5. 실행·검증 기록

### 로컬·Dev 검증

- 새 메인 집계: Dev 실데이터 스냅샷으로 30일 가입 추이와 가입자 카드 합계를 대조했다.

- 추가 집계 분기: push/external 양쪽의 정책상 중단 코드 5종 제외, 재시도 가능 실패 제외, LIVE 수동 진행·취소·비공개 크리에이터 제외를 통과했다.
- 기존 상세 통계의 마지막 부분 날짜 누락도 수정하고, 일별 가입자 합계가 선택기간 총계와 일치함을 SQL로 검증했다.
- 어드민·분석·권한 관련 36개 파일 137개 테스트를 통과했다. 최종 통합 타입 검사·프로덕션 빌드 결과는 릴리스 기록에 남긴다.
- Dev 보안 advisor: 오류 0건. 기존 다른 함수의 실행 권한 관련 경고 14건은 이번 변경 범위 밖이며, 새 `read_admin_overview` 관련 경고는 없다.
- 넓게 실행한 기존 전체 G6 검사에서는 저장소에 포함되지 않은 과거 PPT 검증 문서 때문에 계약 테스트 1건이 실패했다. 새 어드민 CI는 실제 관련 어드민·분석·권한 API 테스트를 명시해서 실행한다. 과거 문서를 새로 만들어 통과한 것처럼 처리하지 않는다.
