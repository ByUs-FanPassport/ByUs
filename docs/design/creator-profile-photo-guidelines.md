# 크리에이터 프로필 사진 규약

적용 대상: 홈 최애 카드, 크리에이터 목록, 팬페이지 및 새 프로필 사진 등록·교체 작업.

## 선정 기준

- 본인·소속사가 제공하거나 사용 허가와 출처를 확인한 실제 사진을 사용한다.
- **문신이 드러나는 사진은 프로필에 사용하지 않는다.** 문신이 없는 노출 구도의 사진을 우선 선정한다. 기존 사진은 얼굴을 해치지 않고 문신 영역을 완전히 제외할 수 있을 때만 크롭하여 사용한다. 그렇지 않으면 다른 사진으로 교체한다.
- 얼굴이 선명하고 눈·코·입이 식별되는 사진을 선택한다. 과도한 필터, 흔들림, 저해상도 확대, 얼굴을 가리는 소품이나 워터마크는 피한다.
- 인물의 얼굴이나 문신을 AI로 재생성·삭제하여 맞추지 않는다. 원본 선정과 크롭으로 해결한다.

## 크기와 구도

- 최종 썸네일은 **1:1 정사각형**. 홈 표시 기준은 **240 × 240 CSS px**, 공간이 부족한 화면에서만 비례 축소한다.
- 새로 납품하는 정사각형 파일은 1200 × 1200px 권장, 720 × 720px 이상을 목표로 한다. 기존 사진은 크롭 후 실제 표시 크기에서 선명도를 검수한다.
- 개인 사진은 얼굴 중심의 상반신 구도. 얼굴 높이(이마부터 턱까지)는 정사각형 높이의 약 45–65%를 목표로 하되 자세와 머리 모양에 따라 조정한다.
- 머리 위 여백을 작게 유지하되 머리카락·눈·턱을 자르지 않는다. 양옆 얼굴 윤곽도 온전히 들어오게 한다.
- 전신사진을 그대로 축소하거나, 원본 비율을 유지하느라 좌우에 빈 띠를 만들지 않는다. 인물마다 초점과 확대율을 따로 설정한다.
- 그룹은 **멤버 전원의 얼굴 보존이 우선**이다. 멤버가 모인 영역으로 크롭하고 무대·관객·천장 등 배경 여백을 줄인다. 개인 사진과 얼굴 크기를 억지로 맞추려고 멤버를 자르지 않는다.
- 사진 자체 크롭과 캐러셀 이동 중 노출은 구분한다. 정지한 카드의 사진은 정사각형 프레임 안에 완전히 들어와야 한다.

## 등록·교체 검수

1. 인물·그룹의 동일인 여부, 사진 출처·사용 허가를 확인한다.
2. 문신 노출, 얼굴 가림, 선명도를 확인하고 원본을 선정한다.
3. 원본을 보존하고 크롭 위치·확대율을 기록한다. 동일 사진이라도 개인과 그룹을 일괄 자동 크롭하지 않는다.
4. 데스크톱과 320–390px 모바일에서 실제 크기로 확인한다. 모든 멤버의 얼굴, 문신 미노출, 정사각형, 얼굴 크기, 화살표와의 겹침을 확인한다.
5. 홈·목록·팬페이지별로 반영 여부를 확인한다. 한 화면만 수정했으면 전체 반영으로 보고하지 않는다.

## 현재 홈 조정 기록

- 창하·엘리나: 기존 얼굴 중심 구도를 기준으로 유지.
- 유나: 세로 사진을 정사각형으로 채우고 얼굴 쪽에 초점 설정.
- 엑신: 하단 중앙의 다섯 멤버를 1.6배 확대. 전원 얼굴과 양끝 멤버 보존.
- 박명호: 기존 원본의 얼굴 영역만 1.9배 확대해 문신이 있는 팔을 프레임에서 완전히 제외. 원본과 다른 화면의 사진은 교체하지 않았음.
- 이퓨: 얼굴과 어깨 중심으로 2.45배 확대해 전신사진의 과도한 여백 제거.

이 규약은 사진 선정·검수 기준이다. CMS 업로드 자동 검사 기능이 구현되어 있다는 의미는 아니다.

## 가로 히어로 배너 규격

프로필 썸네일과 **별도 원본**으로 관리한다. 세로 프로필을 가로 배너에 강제로 확대해 눈·이마·머리를 자르는 사용은 금지한다.

| 항목 | 데스크톱 가로 배너 | 모바일 배너 |
| --- | --- | --- |
| 비율 | 2:1 (현재 팬페이지 16:8) | 4:5 |
| 권장 납품 크기 | 2720 × 1360px | 1080 × 1350px |
| 최소 목표 크기 | 1920 × 960px | 720 × 900px |
| 인물 위치 | 오른쪽 영역에 머리와 얼굴 전체, 왼쪽은 제목·버튼용 여백 | 상단·중앙에 얼굴 전체, 하단은 제목·버튼용 여백 |

- 원본 촬영 단계에서 가로 구도를 확보한다. 개인은 상반신과 주변 여백, 그룹은 전원 얼굴이 충분히 크게 보이는 단체 구도를 선택한다.
- 눈·코·입·턱과 머리 위가 안전 영역 안에 들어오도록 한다. 얼굴과 머리 외곽은 프레임 가장자리에서 최소 5% 여유를 둔다.
- 데스크톱 왼쪽 약 45%, 모바일 하단 약 35%는 카피·버튼 영역으로 검수한다. 얼굴 위에 글자나 버튼을 올리지 않는다.
- 모바일은 같은 가로 이미지를 중앙 자동 크롭하지 않고 별도 4:5 구도와 초점을 준비한다.
- 고화질은 파일 용량이 아니라 최종 크기의 선명도로 판단한다. 눈·머리카락이 뭉개지거나 강한 업스케일 흔적이 있으면 다른 원본을 요청한다.
- 적합한 가로 사진이 없으면 세로 사진의 비율을 유지하고 단색 배경과 함께 배치한다. 이를 임시 대체 표시로 기록하고, 가로 사진을 확보했다고 보고하지 않는다.
- 저장 시 데스크톱·모바일 원본, 출처, 크기, 초점, 검수 화면을 별도로 기록한다. 현재 CMS에 전용 필드가 자동으로 마련되어 있다는 뜻은 아니다.

## 원형 프로필 규격

- 원본은 별도 **1:1 정사각형 720 × 720px 이상** 권장. 현재 팬페이지 표시 크기는 **64 × 64 CSS px**이다.
- 정사각형 전체가 아니라 **원형 마스크를 적용한 결과**로 검수한다. 모서리에 놓인 머리·얼굴은 원에서 잘리므로 얼굴을 중앙으로 옮긴다.
- 개인은 얼굴 높이를 원 지름의 약 45–60%로 맞추고, 머리 위에 원 지름의 약 8–12% 여백을 확보한다. 얼굴 중심은 원 중심 가까이에 둔다.
- 눈·턱·머리 위와 양옆 얼굴 윤곽을 보존한다. 헤어스타일에 따라 확대율을 줄이는 것을 허용한다.
- 그룹은 모든 얼굴이 원 내부에 들어오는 별도 단체 크롭을 사용한다. 64px에서 식별하기 어렵다면 그룹 공식 심벌이나 별도 승인된 프로필 원본을 마련한다.
- 64px 실제 표시와 2배 해상도에서 확인한다. 정사각형 카드용 초점을 원형에 그대로 재사용하지 않는다.

### 유나 팬페이지 적용 상태

2026-09-06: 공식 Instagram 게시물의 2730 × 1820px 가로 사진을 팬페이지 배너에 별도로 연결했다. 기존 세로 사진 대체 표시는 해제했으며 원형 프로필 조정은 유지했다. 로컬 정적 이미지로 반영했고 CMS 원본은 변경하지 않았다.

### 배너 원본과 화면별 초점 관리

- 팬페이지 배너 매핑은 `apps/web/components/fan-ui/creator-hero-images.ts`에서 관리한다. 홈·원형 프로필 이미지는 별도로 유지한다.
- 원본 파일은 `apps/web/public/images/celebrities/{slug}/`에 보존하며 화면에서는 Next Image로 필요한 크기를 제공한다. 사진을 AI로 수정하거나 업스케일하지 않는다.
- PC·모바일은 각각 초점을 지정한다. 엑신은 모든 멤버를 보존하기 위해 가로·세로의 서로 다른 공식 콘셉트 사진을 사용한다.
- 가로 원본을 확보하지 못한 인물은 세로 원본을 검수해 사용한다. 아렴은 PC에서 비율을 보존한 우측 배치, 이퓨는 여백이 넓은 스튜디오 사진의 상반신 크롭을 사용한다. 이를 가로 촬영 원본으로 기록하지 않는다.
