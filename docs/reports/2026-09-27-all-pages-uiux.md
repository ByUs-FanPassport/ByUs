# 로그인 후 전체 페이지 UI·UX 개선

검토일: 2026-09-26–27 KST. 대상: ByUs 웹, PC 1440px와 모바일 390px. 변경 영향이 큰 헤더·신청 내역은 320px도 확인했다.

## 범위와 방법

`app/**/page.tsx` 90개 경로 템플릿(팬·공개 58, 관리자 28, 인터셉트 모달 4)을 목록화했다. 별칭, 인증 완료 리다이렉트, 데이터가 필요한 상세 화면을 서로 구분했다. 90개 경로를 90개의 독립 화면으로 세지 않는다.

탐색·팬페이지·LIVE, MY·혜택·지원, 관리자 영역을 독립 담당자가 검토했다. 기존 로그인 세션으로 실제 페이지와 하위 링크를 열었고, 수정 코드는 다른 담당자가 교차 검토했다. 운영 데이터가 없는 화면은 기존 로컬 검증 환경과 합성 데이터로 보완했다. 운영 응모·예약·게시·배송 정보 저장·계정 변경은 실행하지 않았다.

승인된 사진·캘린더 아트워크, Pretendard, 흰 바탕과 진한 글자, 분홍·보라 강조색을 유지했다. 이미 있는 Fan UI 구성 요소를 재사용했다.

## 반영한 변경

## 검증 근거

- Node 24에서 전체 웹 검사 546개 파일·4,260개 테스트 중 4,259개 통과. 나머지 1개는 한글로 변경한 미션 통계 문구를 영어로 검사하던 계약 테스트였으며, 기대 문구 수정 후 해당 계약·컴포넌트 4개 테스트를 통과했다.
- 변경본의 타입 검사, 웹 린트, 프로덕션 빌드 통과. 다른 작업의 TikTok LIVE 변경을 최신 main에서 통합한 뒤 관련 7개 파일·108개 테스트를 통과했다. 마지막 게시글·공유 화면 보완 후 관련 8개 테스트와 린트·프로덕션 빌드도 통과했다.
- 수정 후 실제 화면 근거: MY 390/1440, 신청 내역 320/390/1440, 팬페이지 헤더 320·탭 390, 혜택 390/1440·확인 모달 390, 관리자 일정 390·신청 목록 1440.
- 운영에 활성 미션이 없어 기존 미션 로컬 환경에서 PC·모바일, 키보드 선택과 다음 퀴즈 이동을 확인했다.

관리자 28개 경로는 PC와 모바일 모두 확인했다(27개 실제 화면, 인증 상태의 로그인 경로 리다이렉트 1개). 모바일에서 페이지 전체의 가로 넘침은 없었다. 게시글·치지직 소식·인증 질문·인증 결과·LIVE 설문·당첨자 수령·공유 패스포트 등 운영 데이터가 없는 상태도 로컬에서 양쪽 폭으로 렌더해 확인했다. 혜택의 PC 서랍형 모달과 모바일 모달도 확인했다.

로컬 상세 증거는 `work/allpages-uiux-20260927/`에 보관한다. 관리자 화면과 사용자 정보가 포함될 수 있어 원본 캡처를 Git에 일괄 포함하지 않는다. 하위 `coverage.csv`는 실제 화면, 별칭, 빈 상태, 시험 데이터, 데이터 제한을 구분한다.

## 근거의 한계

- 당첨자 수령과 공유 패스포트는 운영 계정에 해당 데이터가 없어 로컬 합성 데이터로 확인했다. 이는 운영 당첨·배송·공유 성공을 의미하지 않는다.
- 로그인 인터셉트 모달은 별도 실화면을 검증하지 않았다. 로그인 페이지의 인증된 상태와 복구 화면을 확인한 결과를 모달 검증으로 대체하지 않는다.
- 완료된 계정의 온보딩은 홈으로 이동하며, Kakao 콜백은 파라미터 없는 복구 상태만 확인했다.
- 임베디드 모바일 환경의 로그인 페이지에서 브리지 오류 상태가 노출됐다. 기존 로그인 세션으로 다른 화면은 확인했으며, 이 결과만으로 일반 기기의 로그인 실패를 단정하지 않는다.
- 전체 페이지 캡처에서 고정 헤더가 반복되는 도구의 합성 현상과 잘못된 데스크톱 캡처는 결함·검수 근거에서 제외했다.
- 설정의 긴 페이지 구성과 모바일 하단 링크 밀도는 남은 소규모 개선 후보다. 이번에는 접근 차단·오류·일관성이 떨어지는 화면을 우선 보완했다.
